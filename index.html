Equip as Chrome New Tab Page

Step 1: Export Self-Contained File

Save this standalone index.html file to a permanent folder on your computer.

Step 2: Set as Your Chrome New Tab

  1. Double-click your downloaded index.html to open it in Chrome and copy its address bar path (starts with file:///...).
  2. Install the free Custom New Tab URL extension from the Chrome Web Store.
  3. Paste your local file:/// URL into the extension options and click Save.
  4. Alternatively, add it under chrome://settings/onStartup → Open a specific page or set of pages.
